# 🌐 Life 2.0 – Web Game Project

Selamat datang di repository **Life 2.0**, sebuah website interaktif bertema game yang dikembangkan sebagai **Tugas Besar Mata Kuliah Proyek Pemrograman Web**.

Proyek ini dibuat oleh **Tim 1** dan dirancang untuk menyajikan konsep **game simulasi kehidupan** dalam bentuk website promosi yang sinematik, interaktif, dan responsif.

---

## 🎮 Tentang Proyek

**Life 2.0** adalah sebuah website konsep untuk game bertema **simulator kehidupan**, di mana pengguna dapat merasakan pengalaman virtual dalam dunia futuristik melalui tampilan yang imersif dan dinamis.
